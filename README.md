# GARoute

GARoute (Genetic Algorithm Route) — учебное приложение для поиска и сравнения маршрутов генетическим алгоритмом.

Проект находится в `C:\GARoute`. Основная ветка Git — `main`.

Сейчас идёт поэтапная разработка по [техническому заданию](SPEC.md) и [плану](IMPLEMENTATION_PLAN.md). Рабочий статус и результаты проверок записываются в [CURRENT_TASK.md](CURRENT_TASK.md) и [PROGRESS.md](PROGRESS.md). Приложение пока не готово к запуску.
