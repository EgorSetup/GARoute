# GARoute

GARoute (Genetic Algorithm Route) — учебное приложение для поиска и сравнения маршрутов генетическим алгоритмом.

Проект находится в `C:\GARoute`. Основная ветка Git — `main`.

Сейчас идёт поэтапная разработка по [техническому заданию](SPEC.md) и [плану](IMPLEMENTATION_PLAN.md). Рабочий статус и результаты проверок записываются в [CURRENT_TASK.md](CURRENT_TASK.md) и [PROGRESS.md](PROGRESS.md).

## Текущая версия

Локальный интерфейс загружает реальную автомобильную сеть OSM для утверждённой области. Нажмите «Загрузить дороги», выберите A/B на карте, пресет и режим нормализации, затем «Показать P0» и «Рассчитать». Результаты содержат сохранённые запуски, поколения и графики; отношения OSM, которые нельзя применить однозначно, отражены в диагностике.

По умолчанию действует строгий режим: отсутствующий или неоднозначный `maxspeed` блокирует расчёт. В загруженной области 170 доступных рёбер не имеют этого тега. Для учебного расчёта откройте «Учебная модель скоростей», вручную заполните скорости в км/ч для показанных классов и явно включите переключатель. Числовых значений по умолчанию нет. Непокрытые классы и неоднозначные speed-теги продолжают блокировать расчёт. Карточка результата показывает введённые значения, их применение в лучшем маршруте и зависимость T от модели; исходные OSM-теги не изменяются. Изменение режима или значений после расчёта требует подтверждения очистки истории.

## Локальный запуск на Windows

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Открыть `http://127.0.0.1:8080`. Проверки: `.\.venv\Scripts\python.exe -m pytest -q`.

Демонстрационные режимы для проверки событий карты и подтверждения изменений включаются только переменными окружения `GAROUTE_MAP_EVENT_TEST=1` и `GAROUTE_CHANGE_TEST=1`. Их данные искусственные и не являются результатами расчёта.
