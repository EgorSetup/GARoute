# GARoute

GARoute (Genetic Algorithm Route) — учебное приложение для поиска и сравнения маршрутов генетическим алгоритмом.

Проект находится в `C:\GARoute`. Основная ветка Git — `main`.

Сейчас идёт поэтапная разработка по [техническому заданию](SPEC.md) и [плану](IMPLEMENTATION_PLAN.md). Рабочий статус и результаты проверок записываются в [CURRENT_TASK.md](CURRENT_TASK.md) и [PROGRESS.md](PROGRESS.md).

## Текущая версия

После этапа T01 доступен локальный интерфейс: карта, настройки ГА/Fitness, каталог штрафов, пустая панель результатов и подтверждение изменения условий. Дорожный граф, поиск маршрута, расчёт Fitness и графики по поколениям ещё не подключены. Незавершённые действия отключены.

## Локальный запуск на Windows

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Открыть `http://127.0.0.1:8080`. Проверки: `.\.venv\Scripts\python.exe -m pytest -q`.

Демонстрационные режимы для проверки событий карты и подтверждения изменений включаются только переменными окружения `GAROUTE_MAP_EVENT_TEST=1` и `GAROUTE_CHANGE_TEST=1`. Их данные искусственные и не являются результатами расчёта.
